## Carbohydrates, Fats and Proteins
<!-- subtopic: 51f41ca0-b474-45f4-acd3-b583868a0fe0 -->

| Front | Back |
|-------|------|
| Which elements make up carbohydrates? | Carbon, hydrogen and oxygen (C, H, O). |
| Which elements make up fats (lipids)? | Carbon, hydrogen and oxygen (C, H, O). |
| Which elements make up proteins? | Carbon, hydrogen, oxygen and nitrogen (C, H, O, N). |
| Which element is found in proteins but not in carbohydrates or fats? | Nitrogen. |
| What is the main role of carbohydrates? | An immediate source of energy (glucose is broken down in respiration). |
| What is the main role of fats (lipids)? | Long-term energy storage and insulation. |
| What is the main role of proteins? | Growth and repair of cells. |
| Food test for starch, and the positive result? | Add iodine solution; it turns blue-black. |
| Food test for reducing sugar, and the positive result? | Add Benedict's solution and heat; a brick-red precipitate forms. |
| Food test for protein, and the positive result? | Add biuret solution; it turns violet/purple. |
| Food test for fats, and the positive result? | Dissolve in ethanol, then add water; a cloudy white emulsion forms. |
| What must you remember to do in the Benedict's (reducing sugar) test? | Heat it in a water bath. |
| Starch, glycogen and cellulose are built from which basic unit? | Glucose. |
| Proteins are built from which basic units? | Amino acids. |
| Fats (lipids) are built from which basic units? | Glycerol and fatty acids. |
| What is the storage form of glucose in animals? | Glycogen (in plants it is starch). |

## Enzymes
<!-- subtopic: becf9975-53fe-4986-8670-eb5825d45ecc -->

| Front | Back |
|-------|------|
| What is an enzyme? | A biological catalyst — a protein that speeds up a reaction and is not used up. |
| How do enzymes speed up reactions? | By lowering the activation energy. |
| What is the active site of an enzyme? | The part of the enzyme with a specific shape where the substrate binds. |
| What forms when a substrate binds to the active site? | An enzyme-substrate complex. |
| Why is each enzyme specific to one substrate? | Its active site has a shape complementary to only that substrate (lock and key). |
| Are enzymes used up in the reaction? | No — they are unchanged and can be reused. |
| State the lock and key hypothesis. | Only a substrate with a complementary shape fits the enzyme's active site, like a key in a lock. |
| What happens to the rate as temperature rises to the optimum? | It increases, because molecules collide more often. |
| What is the optimum temperature for human enzymes? | About 37°C. |
| What happens to an enzyme above its optimum temperature? | It is denatured — the active site changes shape so the substrate no longer fits. |
| Is denaturing reversible? | No — it is permanent. |
| What happens to an enzyme at low temperature? | It becomes slow/inactive but is not denatured; it speeds up again when warmed. |
| What happens to an enzyme if the pH is too high or too low? | The active site changes shape and the enzyme is denatured. |
| What does "denatured" mean? | The active site has permanently changed shape, so the substrate can no longer fit and the reaction stops. |
